# Academia del Helado — sitio web

Sitio estático bilingüe (ES/EN) del **Kit del Heladero / Ice Cream Maker's Toolkit**: herramientas de Excel para formular, costear y controlar una heladería artesanal.

- Español: `index.html` · English: `en/index.html`
- Sin dependencias ni servidor: HTML + CSS + un script pequeño (mini-calculadora de recargo vs. margen).
